# Personal Expense Analysis 💰

## About the Project
Personal Expense Analysis is a beginner-friendly project that helps users understand their spending habits using Python and data visualization.

## Features
- Upload expense data using a CSV file
- Calculate total, average, and highest expenses
- Visualize expenses by category using a pie chart
- View monthly expenses using a bar chart
- Display transaction history in a table

## Technologies Used
- Python
- Pandas
- Matplotlib
- Streamlit

## Dataset
The `expenses.csv` file contains:
- Date
- Category
- Amount

## How to Run
1. Install Python.
2. Install the required libraries:

   `py -3.13 -m pip install streamlit pandas matplotlib`

3. Open Command Prompt in the project folder.
4. Run the app:

   `py -3.13 -m streamlit run app.py`

5. Upload your CSV file to view the dashboard.
